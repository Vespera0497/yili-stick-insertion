# Proteus电路仿真说明

## 项目：伊利雪糕三棒签同步插签设备

### 一、仿真电路组成

| 元件 | 型号/参数 | 数量 | 功能 |
|------|-----------|------|------|
| 单片机 | STC89C52RC | 1 | 主控，执行三缸同步控制算法 |
| 电磁阀 | 直流24V（用LED模拟） | 3 | 控制三个气缸伸缩 |
| 位置传感器 | 限位开关 | 3 | 检测气缸是否到位 |
| 急停按钮 | 常闭按钮 | 1 | 紧急停止 |
| 指示灯 | LED（红/绿） | 2 | 运行指示、告警指示 |
| 电源 | DC5V | 1 | 单片机供电 |

### 二、在Proteus中搭建步骤

1. 打开Proteus 8，新建工程
2. 从元件库中选择以下元件：
   - `AT89C52`（单片机）
   - `LED-RED`、`LED-GREEN`（指示灯）
   - `BUTTON`（按钮）
   - `RES`（电阻）
   - `POWER`、`GROUND`（电源和地）
3. 按照以下连线：
   - P1.0 → LED1（电磁阀1模拟）
   - P1.1 → LED2（电磁阀2模拟）
   - P1.2 → LED3（电磁阀3模拟）
   - P2.0 → 按钮1（到位传感器1）
   - P2.1 → 按钮2（到位传感器2）
   - P2.2 → 按钮3（到位传感器3）
   - P2.3 → 急停按钮
   - P3.0 → 运行指示灯
   - P3.1 → 告警指示灯
4. 将Keil编译生成的`.hex`文件加载到单片机中
5. 点击运行按钮，开始仿真

### 三、仿真验证流程

1. 点击运行，观察LED3（长缸电磁阀）最先亮起（延时0ms）
2. 125ms后，LED2（中缸电磁阀）亮起
3. 250ms后，LED1（短缸电磁阀）亮起
4. 模拟按下三个到位传感器按钮，观察三缸同步到位效果
5. 按下急停按钮，所有LED熄灭，告警灯亮起

### 四、与实际硬件的对应关系

| Proteus仿真 | 实际硬件 |
|-------------|----------|
| LED | 电磁阀线圈（通过继电器驱动） |
| 按钮 | 气缸到位磁性开关 |
| 51单片机 | PLC（西门子S7-1200或三菱FX） |
| 5V电源 | PLC DC24V输出 |

---

**说明：** Proteus仿真用于验证控制逻辑的正确性，实际硬件使用PLC控制，算法逻辑完全一致。
