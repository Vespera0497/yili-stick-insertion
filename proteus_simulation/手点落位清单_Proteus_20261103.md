## 一、要放的东西（每路一条，共 3 路，低有效）

拓扑：**+5V(POWER 端) → RES(470Ω) → LED-RED 的 A → LED-RED 的 K → U1 的 P1.x**
（P1.x 拉低时 LED 亮，符合固件的低有效驱动；8051 灌电流也比拉电流靠谱。）

| 路 | 接到 U1 脚 | 需要的元件 |
|---|---|---|
| LED1 | P1.0 | 1× LED-RED + 1× RES |
| LED2 | P1.1 | 1× LED-RED + 1× RES |
| LED3 | P1.2 | 1× LED-RED + 1× RES |

## 二、点法（Proteus 正常手顺，别用双击 DEVICES——双击会弹 Pick Devices 吃掉点击）

1. 左侧模式条点 **Component Mode**（第二个图标，三角形那个）。
2. 在右侧 DEVICES 列表里**单击** `LED-RED` → 元件跟着光标 → 在图纸空白处**单击**落一个；重复到 3 个。
3. 同样单击 `RES` 落 3 个。
4. 改电阻值：双击某个 RES → Component Value 里把 `1k` 改成 `470` → OK。（三个都改，或改一个后复制它两份更省事。）
5. 左侧模式条点 **Terminal Mode**（接地/电源符号那个图标）→ 在每条电阻外侧单击放 `POWER`（默认 +5V）；若你走“P1→R→LED→GND”的反向接法，就放 `GROUND`。
6. 点 **Wire Mode**（第三个图标）→ 从引脚端点单击到另一端点单击，画 3 条通路：`POWER↔RES`、`RES↔LED(A)`、`LED(K)↔P1.x`。导线端点必须压住引脚末端的小方块（压住时会变红/吸附）。
7. （可选，但 §1-2 的急停判据要用）再放 1 个 `BUTTON`：一端接 **P2.3**、另一端接 `GROUND`；P2.3 同时接一个上拉电阻到 POWER。急停断开 = 按下按钮，看是否全灭+告警。
8. （可选，UART 字节流要用）左下 **Virtual Instruments Mode**（电流表/示波器那一列）→ 选 `VIRTUAL TERMINAL` → 放一个 → 两条线：VT 的 `RXD` 接 **P3.0**、VT 的 `TXD` 接 **P3.1**（9600-8N1 在 VT 属性里设：双击 VT → Properties → 波特率 9600、数据 8、停止 1、校验 None）。
9. **Ctrl+S 保存工程**，然后回我一句「存好了」。
