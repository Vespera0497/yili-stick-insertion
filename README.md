# 伊利雪糕三棒签同步插签自动化设备

**项目时间**：2026.07 – 2026.09（内蒙古蒙辰轻工机械有限公司实习期间）
**项目性质**：三缸同步插签自动化控制系统的方案设计与仿真验证
**技术栈**：Altium Designer（层次原理图） · Keil C51（AT89C52 固件，含 UART） · C 语言（核心控制算法） · Qt6（上位机） · MATLAB（运动学仿真） · Proteus（电路仿真） · SolidWorks（机构装配）

---

## 一、项目背景

雪糕插签工序需要把三根棒签插入雪糕成型。早期方案假设三根签长度不同，用 30/45/60 mm 差异化行程加 250/125/0 ms 延时去凑"同时到位"。经装配模型复核，木签实际为 10×10×150 mm 三根同长，差异化行程会导致插签深度不一致。因此最终方案改为**统一 30 mm 行程、按 0/125/250 ms 错峰启动**，纳入完整的保持与复位时序。

> 本项目为方案设计与仿真验证，所有画面均为软件界面、仿真与模型动画，不是实机录像。

## 二、统一参数口径（v2 定稿）

| 项 | 取值 |
|---|---|
| 木签 | 10×10×150 mm，三根同长 |
| 推杆初始位 / 行程 | 72 mm / 统一 30 mm |
| 启动延时 | 0 / 125 / 250 ms（相邻气缸错峰 125 ms） |
| 单缸动作 | 200 ms |
| 到位时刻 | 200 / 325 / 450 ms（错峰差 250 ms，设计值） |
| 同步保持 / 复位 | 500 ms / 350 ms |
| 仿真总时长 | 1300 ms |
| 控制周期 | 5 ms |

早期口径（30/45/60 mm、250/125/0 ms、650 ms 到位、700 ms 总长）已全部作废。

## 四、运行与验证

### 4.1 核心控制算法

```bash
python src/stick_insert_control.py                       # Python 仿真
gcc src/stick_insert_control.c -o sim.exe -lm && ./sim.exe   # C 语言版
```

输出为三缸按 125 ms 等间隔错峰启动、450 ms 全部到位、随后同步保持与复位，末尾给出错峰判定结果。

### 4.2 MATLAB 运动学仿真

在 MATLAB 中运行 `matlab/stick_insert_simulation.m`，输出统一 30 mm 行程下的三缸位置曲线（0–1300 ms）与错峰到位分析。

### 4.3 Qt 上位机

用 Qt Creator 打开 `qt_gui/CMakeLists.txt`，编译后运行。可设置三缸行程与错峰延时，实时查看位置曲线、到位状态与运行日志。

### 4.4 Altium 层次原理图

`ad_schematic/` 下为 Main 顶层 + P1~P5 子图的层次原理图工程，含 43 个元件、167 个引脚、46 段导线与 4 个 Junction，AD 原生 Validate 结果为 0 Error。

## 五、主要工作

- 依据装配模型复核并统一了木签规格与三缸行程，制定了以错峰启动替代差异化行程的同步方案。
- 编写 C 语言控制算法、AT89C52 固件（含 UART 协议）与 Python 同算法仿真。
- 开发 Qt6 上位机监控界面与 Web 监控看板。
- 用 MATLAB 完成运动学仿真、Proteus 完成电路仿真，验证错峰时序。
- 绘制 Altium 层次原理图，完成网表与 BOM 一致性核验。
- 完成 SolidWorks 机构装配与三维示意图。
