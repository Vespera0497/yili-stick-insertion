# 三棒签同步插签设备 · 固件设计文档（FW）

> 版本：v1.0 · 2026-10-30 · 状态：基线已实现；**UART 扩展(S1)进行中**

## 1. 开发环境
- Keil µVision（C51），工程 `keil_firmware\control.uvprojx`，源码 `main.c`。
- 芯片 STC89C52RC（AT89C52 同脚位）；`reg52.h` + `intrins.h`。
- 编译：F7 出 `control.hex`（基线 1,415B）。Ctrl+F5 调试器因缺 AT89C52 器件库不可用 → 验证靠 Proteus。

## 2. 架构（基线 main.c）
- **Timer0 模式1**：1ms 节拍，`timer_ms` 全局计数（中断 `Timer0_ISR` 自增）。
- **主循环**：急停检查 → 启动流程 → 三缸按 DELAY 差异化启动 → 全到位判定(≥650ms)→ 成功保持 500ms 复位 → 超时(≥1000ms)告警复位。
- **急停 `Check_EStop()`**：SB1==0 → 三缸断电、RUN 灭、ALARM 亮、停系统。

## 3. 控制参数（基线）
| 宏 | 值 | 含义 |
|---|---|---|
| DELAY1/2/3 | 250/125/0 ms | YV1/2/3 启动延时 |
| CYLINDER_TIME1/2/3 | 400/525/650 ms | 各缸行程时间 |
| 同步阈值 | 650 ms | 三缸全到位 |
| 超时阈值 | 1000 ms | 告警复位 |

## 4. UART 扩展设计（S1，待实现）
- **挪灯脚**：LED_RUN/LED_ALARM 由 P3.0/P3.1 → **P3.2/P3.3**（释放硬件 UART 脚）。
- **UART 初始化**：Timer1 模式2 自动重载，9600/8N1（TH1=0xFD），SCON=0x50，ES/EA 使能。
- **上行帧**：状态帧 TYPE 0x01(14B，≥10Hz) + 事件帧 TYPE 0x02(6B)；字段严格按 `UART_PROTOCOL_v1.md`。
- **下行解析**：命令帧 TYPE 0x81(3B) → 启动/停止/复位/参数下装。
- **封装**：`AA 55|LEN|TYPE|PAYLOAD|SUM`，SUM=(LEN+TYPE+PAYLOAD)&0xFF。
- TMP/PRS 未接线前发哨兵 0x7FFF / 0xFFFF。

## 5. 验收（S1 完成后）
- F7 编译 0 Error；新 `control.hex` 报告字节数 + MD5。
- Proteus 加载验证 UART 字节流（S2 上位机联调前）。
