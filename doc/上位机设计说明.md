# 三棒签同步插签设备 · 上位机设计说明（S2）

> 版本：v0.2(实现中) · 2026-10-30 · 状态：S2 主体已交付——协议层 35/0 自测通过、SQLite 推送实跑落库、GUI 有双后端（start.py 自动选：PySide6 损坏时落 tkinter 回退版 main_tk.py，已实测）；待真机串口联调 + 运行截图

## 1. 定位
PC 端控制程序，技术栈 **Python（PyQt/PySide）** 桌面 GUI，经串口与 8051 双向通信。

## 2. 职责
- **接收**：设备状态帧(TYPE 0x01)、事件帧(TYPE 0x02)。
- **下发**：启动/停止/复位/参数(TYPE 0x81)。
- **数据源**：作为监控数据源头，经本地接口(WebSocket / 本地 HTTP / 共享 SQLite)推送给独立监控看板(§监控设计说明)。

## 3. 通信层
- `pyserial` 读写；波特率 9600/8N1；物理层 CH340/CP2102（USB 虚拟串口）。
- 帧解析严格按 `UART_PROTOCOL_v1.md`：AA55|LEN|TYPE|PAYLOAD|SUM。

## 4. 界面（PyQt/PySide）
- 连接设置（串口号/波特率）、启动/停止/复位按钮。
- 实时状态面板：三缸 YV1-3、三到位 SQ1-3、急停、RUN/ALARM、产量计数、节拍。
- 日志区：事件帧时间戳记录。

## 5. 运行（一键）
- `python main.py` 起 GUI + 自动连串口；根目录放 `README_运行.md` 写清三步。
- 开发 IDE：PyCharm（项目本体工具）。

## 6. 依赖
- 必须先完成 S1（固件 UART），否则上位机无协议可联调。
- MATLAB 默认不引入。
