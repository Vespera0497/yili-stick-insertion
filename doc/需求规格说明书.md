# 三棒签同步插签设备 · 需求规格说明书（SRS）

> 版本：v1.0 · 2026-10-30 · 状态：基线已定，扩展项(通信/上位机/监控)已纳入

## 1. 产品概述
伊利雪糕"三棒签"同步插签设备，对三根长度不同的签（短缸 30mm / 中缸 45mm / 长缸 60mm）做**差异化延时同步控制**，使三缸在约定节拍内同步到位、完成插签动作。

## 2. 功能需求（核心）
| 编号 | 功能 | 说明 |
|---|---|---|
| FR-1 | 三缸差异化延时启动 | YV3(长缸)立即、YV2(中缸)延 125ms、YV1(短缸)延 250ms 启动 |
| FR-2 | 同步到位判定 | SQ1/SQ2/SQ3 全到位且 ≥650ms → 同步成功 |
| FR-3 | 急停保护 | SB1(常闭)断开 → 三缸断电、亮告警、停系统 |
| FR-4 | 运行/告警指示 | LED_RUN 绿(运行)、LED_ALARM 红(告警/同步成功) |
| FR-5 | 超时保护 | ≥1000ms 未全到位 → 告警并复位 |

## 3. 功能需求（本次扩展新增）
| 编号 | 功能 | 说明 |
|---|---|---|
| FR-6 | 串口通信 | 8051 经 UART(9600/8N1) 上行状态/事件、下行指令，桥接 CH340/CP2102 |
| FR-7 | 上位机(PC) | Python(PyQt/PySide) 桌面程序，收发串口数据、下发启动/停止/复位 |
| FR-8 | 监控系统 | 独立 Web 看板，只读记录运行状态/产量/故障/扩展指标 |

## 4. 性能需求
- 单循环节拍：三缸全部到位 ≤ 650ms；超时阈值 1000ms。
- 通信：状态帧上行 ≥10Hz；波特率 9600（11.0592MHz 无误差）。
- 扩展指标：温度、气压经额外传感器上报（型号待定，先预留接口）。

## 5. 接口需求
- 硬件 UART：P3.0=RXD、P3.1=TXD → CH340C(TTL→USB) → PC。
- 通信协议：`UART_PROTOCOL_v1.md`（已锁定，帧 AA55|LEN|TYPE|PAYLOAD|SUM）。
- 上位机→监控：本地接口 WebSocket / 本地 HTTP / 共享 SQLite（三选一）。

## 6. 验收标准
1. Proteus 仿真 LED 时序符合 FR-1/FR-4（LED3→LED2→LED1→≥650ms 绿灯→急停全灭告警）。
2. Keil 固件 F7 编译通过（Ctrl+F5 调试器不可用，不计入验收）。
3. UART 协议锁定且字节流可解析（Virtual Terminal 可见）。
4. 上位机可连串口收状态帧、下发启动/停止/复位。
5. 监控看板四类数据(实时/产量/故障/扩展)可显示与落盘。
6. 文档体系、PPT、演示视频齐备。
