## 4. 表 C ｜电气审计：打样前必须处理的 10 项（F1~F5 阻断/高，F6~F10 补齐）

### F1 ⛔ 复位网络极性反接（会让板子永远复位）

现状（v16 网表）：`C3: RESET ↔ GND`，`R1: RESET ↔ +5V`。

上电瞬间 C3 相当于短路 → RST = 0V；随后 C3 经 R1 充电，RST 升到 +5V 并**一直保持 +5V**。AT89C52 的 RST 是**高电平有效**，因此上电约 0.1s 后芯片被永久按在复位态，程序不跑。

**修正**：C3 改接 `+5V ↔ RST`，R1 改接 `RST ↔ GND`（即经典的"上电高、随后拉低"）。
**验收方法**：上电用示波器/万用表看 RST 对地，应是 **5V→0V 的下降沿**（约 0.1~0.5s），而不是 0V→5V。

### F2 ⛔ ULN2003A 通道错位（三路阀都不会动作）

ULN2003A 的 DIP-16 真实脚序：`1B~7B = 1~7`，`E = 8`，`COM = 9`，`7C~1C = 10~16`。
即：IN1(脚1) 对应的输出是 **OUT1(脚16)**，不是脚 10。

现状：`IN1(1) → 网络 DRV_YV1`，而 `YV1 → 脚10（7C）`；同理 YV2→脚11（6C）、YV3→脚12（5C）。
结果：P1.0 打开的是**通道 1 的基极**，线圈却挂在**通道 7 的集电极**上；通道 7 的输入 IN7 是 NC，永远不导通 → **三个阀全部不动**。

**修正（二选一）**：
- 保持输入 1/2/3 不动，把输出改为 `脚16(1C)→YV1`、`脚15(2C)→YV2`、`脚14(3C)→YV3`；
- 或保持输出 10/11/12 不动，把输入改为 `IN7/IN6/IN5`（脚 7/6/5）。

**验收方法**：P1.0 置高，量 ULN 脚16 对地应≈0.9V（导通），脚10 应≈24V（截止）。

### F3 ⛔ 没有 24V 进线端子

`+24V` 在 SchDoc 里只是一个电源端口，板上没有任何接插件引入 24V（J4 是传感器座，J6 是 USB）。
**修正**：按表 B 增加 J8 + F1 + D3 + C6，构成"端子→保险→防反接→储能→7805"的完整链路（图纸 ⑤ 已按此画）。

### F4 ⚠ 无去耦/储能电容

U1 的 VCC、7805 的输入/输出、CH340C 的 V3 都没有电容。轻则串口丢包、复位误触发，重则 7805 自激。
**修正**：按表 B 补 C4~C9。

### F5 ⛔ CH340C 符号只有 6 个脚，与 SOP-16 实际封装对不上

现有符号引脚：1=TXD、2=RXD、3=D+、4=D-、5=VCC、6=GND。
CH340C（SOP-16）真实脚序：**1=GND、2=TXD、3=RXD、4=V3、5=UD+、6=UD-、16=VCC**。
若直接按 6 脚符号建封装，TXD 会落到焊盘 1（实为 GND）上——**必然不通**。
**修正**：新建 16 脚 CH340C 符号（至少引出 1/2/3/4/5/6/16，其余 DTR#/RTS# 等可保留悬空），再配 SOP-16 封装；V3 接 C8=100nF。

### F6 ⚠ DS18B20 单总线没有上拉

`J5.2(DQ)` 直接连到 `P1.4`，线上一颗电阻都没有。DS18B20 是**开漏**器件，没有上拉就没有高电平，读回全是 0。
**修正**：R8 4.7k，`DQ_TEMP ↔ +5V`。
**验收方法**：传感器不插时 DQ 对地 ≈5V；插上通信时用示波器看到 0/5V 跳变。

### F7 ⚠ BMP280 的 I2C 没有上拉

`I2C_SDA/SCL` 只是两个网络名，总线上无上拉。I2C 同样是开漏，缺上拉则 SCL 不上升、总线永远忙。
**修正**：R9/R10 各 4.7k，`SDA ↔ +5V`、`SCL ↔ +5V`（若模块板上自带 4.7k，可不贴，标 DNP）。
**验收方法**：不通信时 SDA/SCL 对地均 ≈5V。

### F8 ⚠ USB VBUS 直连 +5V（有反灌风险）

`J6.1(VBUS) → +5V`。当 24V 在位、7805 有输出时，USB 线与板内 5V 硬并联；更糟的是板内 24V 失效而 USB 仍插着时，电流方向不可控，**可能反灌进主机 USB 口**。
**修正**：`J6.1` 改接 `VBUS_USB`，串 D4（1N5819）后进 `+5V`：A=VBUS_USB、K=+5V。二极管方向保证“USB 能供板、板不能供 USB”。
**验收方法**：只插 USB 不接 24V，+5V 应为 4.5~4.7V（二极管压降）；只接 24V 不插 USB，USB 座 VBUS 脚对地 0V。

### F10 ⚠ 7805 符号多出两个虚构脚

U2 现有 5 个脚：`IN/GND/OUT/IN2/OUT2`，其中 `IN2` 并到 +24V、`OUT2` 并到 +5V。实物 TO-220 只有 3 脚，多出的两个脚在 PCB 上无处落焊盘。
**修正**：删 `IN2`(4)、`OUT2`(5)，保留 1=IN、2=GND、3=OUT。

### F9 ○ 8051 驱动 ULN2003 的高电平裕量不足（建议）

AT89C52 的 P1 口高电平只能源出约 60µA（准双向弱上拉），而 ULN2003 输入约需 1mA 才可靠导通。教材上的直连方案在实验室能亮灯，但在 24V 阀负载、温度变化下**可能间歇不吸合**。
**修正**：R11~R13 各 10k 上拉到 +5V（低成本兜底）。
**验收方法**：阀吸合瞬间量 P1.0~P1.2 对地应 ≥2.4V；若仍不足，改用 74HC244 缓冲（此时可去掉 R11~R13）。

### F11 ○ 单脚假网络（清理项）

`NC_P13`、`NC_P15`、`NC_P24~NC_P27`、`NC_P34~NC_P37`、`NC_PSEN`、`NC_ALE`、`NC_IN4~NC_IN7`、`NC_OUT3`、`NC_OUT4` 共 18 个只挂一个脚的网络，不影响电气，但会干扰网表比对。
**修正**：删网络标签，脚上贴 No-ERC。

### 安全建议（不改电路也要在装配文件里写明）

- **S-1 急停**：现在急停只作为 MCU 输入（P2.3）。实物上必须用**双触点急停按钮**：一组常闭串在 24V 主回路（F1 之后），另一组接 P2.3 作状态显示。只靠软件停机不合规。
- **S-2 传感器类型**：现输入为"干簧管对 GND 闭合"。若现场改用 **NPN 接近开关（10~30V）**，必须另供 24V 并加分压/光耦隔离，否则 24V 直接打进 P2 口会烧芯片。
- **S-3 7805 散热**：总电流约 50mA，压差 19V → 功耗 ≈0.95W；TO-220 裸片温升约 45~50℃，可用但偏热。建议加小散热片，或改 LM2596 降压模块。
- **S-4 输入保护**：现场长线建议在每个输入口加 100nF 到地；阀输出端已有 ULN2003 内部续流二极管，无需外加。
