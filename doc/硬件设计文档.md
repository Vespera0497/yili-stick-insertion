# 三棒签同步插签设备 · 硬件设计文档（HW）

> 版本：v1.1 · 2026-11-03 · 状态：原理图 v16 已过 Validate（109 条，0 Error）；功能修正见 `doc\目标网表_v17.md`

## 1. 主控芯片
- **AT89C52（8051，DIP-40）**，与 Keil 固件(STC89C52RC)、Proteus(U1=AT89C52) 同一颗芯片、同脚位。
- 晶振 **11.0592MHz**（9600 波特无误差）；EA/VPP(31)→+5V 用片内 ROM。

## 2. 引脚映射（权威，来自 main.c + AD 重画）
| 引脚 | 信号 | 方向 | 说明 |
|---|---|---|---|
| P1.0 / P1.1 / P1.2 | YV1 / YV2 / YV3 | 输出 | 电磁阀(短30/中45/长60mm)，高有效 |
| P2.0 / P2.1 / P2.2 | SQ1 / SQ2 / SQ3 | 输入 | 到位传感器，高=到位，上拉 |
| P2.3 | SB1 | 输入 | 急停，**常闭**，上拉，读0=急停(固件内取反) |
| P3.0 / P3.1 | RXD / TXD | — | **硬件 UART**，接 CH340C（LED 已挪走） |
| P3.2 / P3.3 | LED_RUN / LED_ALARM | 输出 | 绿/红指示，**低有效**，各串 470R（从 P3.0/3.1 挪来，腾 UART） |
| P1.4 | DS18B20 | 单总线 | 温度预留（暂发哨兵 0x7FFF） |
| P1.6 / P1.7 | BMP280 | I²C | 气压预留（暂发哨兵 0xFFFF） |

## 3. 支持电路
- 晶振：11.0592MHz → XTAL1(19)/XTAL2(18) 各接 30pF 到 GND（C1/C2）。
- 复位：**高电平复位**——C3 10µF 接 `+5V ↔ RST(9)`、R1 10k 接 `RST ↔ GND`，上电瞬间 RST=5V、约 0.1~0.5s 后降到 0V；S2 轻触为手动复位（可选，与 C3 并联）。
  ⚠ v16 把 C3/R1 接反了（RST 被永久拉高），实物必不启动，见 `目标网表_v17.md` F1。
- 电源：`J8(24V 端子) → F1 2A → D3 1N5819 → +24V`；C6 470µF/50V + C5 100nF 滤波；`7805 → +5V`（C7 100nF 输出、C4 100nF 就近 U1）；VCC(40)→+5V、GND(20)。
- USB：`J6 VBUS → D4 1N5819 → +5V`，只许 USB 供板、不许板反灌主机（F8）。
- 驱动：ULN2003A，`P1.0/1.1/1.2 → IN1/IN2/IN3`，**`OUT1(16)/OUT2(15)/OUT3(14) → YV1/YV2/YV3`**，COM(9)→+24V（内置续流二极管靠它才有回路），E(8)→GND。
  ⚠ v16 把阀接在 OUT7/6/5（脚 11/12/13）上，三路都不会动作，见 F2。
- 输入上拉：SQ1~SQ3 / SB1 各 10k 到 +5V，开关对 GND；SB1 常闭，固件内取反。
- 预留传感器：DS18B20 DQ 加 R8 4.7k 上拉（F6）；BMP280 的 SDA/SCL 加 R9/R10 4.7k 上拉（F7）。

## 4. 串口接口
- **CH340C（TTL→USB）** 桥接，MCU TTL 直转 USB，引到排针/USB-B 座(D+/D-/VBUS/GND)。
- 物理层：CH340/CP2102；**不用** MAX232/RS232。
