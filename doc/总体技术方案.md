## 1. 设计目标与关键指标

**设备**：伊利雪糕三棒签插签设备——将三根冰棒签按设定行程（短/中/长）依次插入雪糕杯的自动化装置。

| 指标 | 目标值 | 说明 |
|---|---|---|
| 主控 | AT89C52 @ 11.0592 MHz | 8051 内核，DIP-40，片内 8 KB Flash |
| 输入 | 3× 到位（干簧管）＋ 1× 急停 | 到位 P2.0~P2.3（10 kΩ 上拉，对 GND 闭合）；急停 SB1 常闭，固件取反 |
| 输出 | 3× 电磁阀驱动 | P1.0~P1.2 高有效 → ULN2003 → YV1/YV2/YV3（DC24V 电磁阀） |
| 行程 | 短 30 / 中 45 / 长 60 mm | 对应三档插签深度 |
| 通信 | UART 9600-8N1 | P3.0/P3.1 → CH340C → USB → 上位机（Python，双后端） |
| 指示 | 2× LED（运行/报警） | P3.2/P3.3，低有效，470 Ω 限流 |
| 电源 | DC24V → +5V | 2A 保险丝 → 1N5819 → 7805 → +5V（7805 前级 24V，后级 5V） |
| 节拍 | 由 MATLAB 核算 | 见 `matlab\stick_insert_simulation.m` 与曲线 |

## 2. 系统架构（六层）

```
┌──────────────────────── 感知层 ────────────────────────┐
│  SQ1/SQ2/SQ3 到位（干簧管，P2.0~P2.3，10k 上拉）        │
│  SB1 急停（常闭，固件取反，P2.x）                        │
└───────────────────────────┬──────────────────────────┘
                              ▼
┌──────────────── 控制层（AT89C52）─────────────────┐
│  P1.0~P1.2 → 驱动电磁阀；P3.2/P3.3 → LED           │
│  P3.0/P3.1 → UART；内部状态机编排插签节拍            │
└───────┬───────────────────────────┬───────────────┘
        ▼                           ▼
┌─ 驱动层（ULN2003） ─┐      ┌── 通信层（CH340C） ──┐
│  YV1/YV2/YV3 电磁阀 │      │  USB → 上位机         │
│  DC24V 感性负载     │      └──────────┬───────────┘
└────────────────────┘                  ▼
                          ┌── 上位层（Python，双后端） ──┐
                          │  协议独立复跑 35/0；SQLite 落库 │
                          │  监控看板（只读）：OEE/良率     │
                          └─────────────────────────────┘
                                      ▲
┌──────────── 电源层 ──────────┐       │
│ DC24V → 2A 保险 → 1N5819      │───────┘（同时供 MCU + 驱动 + 通信）
│ → 7805 → +5V（去耦 0.1 µF）    │
└──────────────────────────────┘
```

## 3. 接口矩阵（MCU 引脚权威分配）

> 完整逐脚表见 `硬件设计文档.md`；此处为系统级速查。

| 端口 | 引脚 | 方向 | 连接 | 说明 |
|---|---|---|---|---|
| P1.0~P1.2 | 1~3 | 输出 | ULN2003 IN1~IN3 | 电磁阀 YV1/YV2/YV3，高有效 |
| P2.0~P2.3 | 21~24 | 输入 | 10 kΩ 上拉 → SQ1/SQ2/SQ3/SB1 | 对 GND 闭合；急停常闭取反 |
| P3.0/RXD | 10 | 输入 | CH340C TXD | 上位机 → MCU |
| P3.1/TXD | 11 | 输出 | CH340C RXD | MCU → 上位机 |
| P3.2/INT0 | 12 | 输出 | 运行 LED（470 Ω） | 低有效 |
| P3.3/INT1 | 13 | 输出 | 报警 LED（470 Ω） | 低有效 |
| XTAL1/2 | 19/18 | — | 11.0592 MHz + 30 pF×2 | 晶振与负载电容 |
| RST | 9 | — | 10 µF + 10 kΩ（RC 复位） | 上电复位 |
| EA/VPP | 31 | — | 接 +5V（电阻） | 片内 ROM 执行 |
| GND | 20 | — | 地 | 单轨供电 |
| VCC | 40 | — | +5V | 主电源 |

## 4. 关键技术决策与理由

| 决策 | 选择 | 理由 |
|---|---|---|
| 主控 | AT89C52（8051） | 教学/量产友好，DIP-40 易手工焊接；11.0592 MHz 精准出 9600 波特率 |
| 驱动 | ULN2003 | 达林顿阵列，直接灌电流驱动 24V 电磁阀，自带续流二极管 |
| 电源 | 7805 线性稳压 | 24V→5V 简单可靠；前级二极管防反接，保险丝限流 |
| 通信 | CH340C | 免晶振 USB-UART，PyCharm/VSCode 上位机零驱调试 |
| 上位机 | Python（双后端：tkinter 生产 / Qt 备选） | 协议已独立复跑 35/0，SQLite 落库，看板只读 |
| 仿真先行 | Proteus + MATLAB | 打样前先在 Proteus 加载 `control.hex` 跑联调，MATLAB 核算节拍，降低实物返工 |
| 图纸/文档 | Ardot 矢量 + `doc\` 工程文档 | 引脚框图/最小系统为 A3 矢量（300 dpi），可复现 |

## 5. 控制逻辑与时序状态机

插签节拍（固件状态机编排，参数基线见固件设计文档）：
1. **待机**：运行 LED 慢闪；等待到位信号。
2. **检测**：SQ1/SQ2/SQ3 全到位 → 进入插签序列；急停 SB1 任何时候触发 → 立即停阀并报警。
3. **插签**：依次驱动 YV1/YV2/YV3，按短(30)/中(45)/长(60) mm 行程定时；每个动作后经 SQ 回检确认。
4. **完成/复位**：整轮完成后回待机；异常（超时/回检失败）点亮报警 LED 并经 UART 上报。
5. **上报**：每次状态迁移经 UART 9600-8N1 发字节帧，上位机落库并在看板呈现。
