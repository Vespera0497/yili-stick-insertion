2026-11-07 · 用户拍板走 **B 方案**（按 v2 重跑并补录），本侧据此统一全项目参数。
**本文件是唯一基准**，MATLAB / Qt / 动画 / 视频字幕 / PPT 一律照此写。

## 1. 为什么不是「改几个数字」

早期运动学仿真假设 **三根木签长度不同 → 三缸行程 30 / 45 / 60 mm，靠差异化延时（250/125/0 ms）凑到同时到位**。
SW v2 实测木签 **10×10×150 mm 三根同长**，推杆若走不同行程必然有的插不到底、有的撞杯底，所以：

> 行程必须**统一 30 mm**；差异化只体现在**启动时刻错峰**，不再是行程补偿。
> 叙事从「差异化延时求同步到位」改为「**统一行程 + 125 ms 错峰启动 → 450 ms 全部到位 → 同步保持 → 同步复位**」。

这不是把旧数字改小，是把早期模型换成最终装配模型。旧版 30/45/60、250/125/0、700 ms **全部作废**。

## 2. 统一参数表

| 项 | 早期（旧画面/旧代码） | **v2 定稿口径** |
|---|---|---|
| 木签 | 假设三根不同长度 | **10×10×150 mm，三根同长** |
| 推杆初始位 | 未定义 | **72 mm** |
| 三缸行程 | 30 / 45 / 60 mm | **统一 30 mm** |
| 顶梁底面→杯口 | — | **149 mm ≥ 70 mm 行程余量**（可明写） |
| 启动延时 | 250 / 125 / 0 ms（长缸先动） | **0 / 125 / 250 ms**（气缸1→2→3，各 125 ms 错峰） |
| 单缸插签动作 | 400 / 525 / 650 ms | **200 ms** |
| 到位时刻 | 声称「三缸同步到位」 | **200 / 325 / 450 ms**（错峰到位差 250 ms，设计值） |
| 同步保持 | 无 | **500 ms**（450→950 ms） |
| 同步复位 | 无 | **350 ms**（950→1300 ms） |
| 仿真 / 动画时长 | 700 ms | 仿真 **1300 ms**；SW 演示动画 **3000 ms / 90 帧 / 30 fps**（含 300 ms 前导 → 动画里全部到位在 750 ms，1.6–3.0 s 静止，首帧=尾帧可循环） |
| 电磁阀时序 | — | YV1 0.30–0.50 / YV2 0.425–0.625 / YV3 0.550–0.750 |

> 300 ms 前导只是动画的视觉留白，不是控制参数；MATLAB/Qt 仿真从 0 ms 起算，故「全部到位 450 ms」与动画「750 ms」相差正好 300 ms，两者不矛盾，写文档时要注明。
