# Altium Designer 原理图设计说明

## 项目：伊利雪糕三棒签同步插签设备 —— PLC控制电路

### 一、设计概述

本原理图为三棒签同步插签设备的PLC控制系统电路图，包含电源、PLC主控、三路气缸电磁阀驱动、位置传感器反馈、急停与过载保护、外部端子排等完整模块。

### 二、在 Altium Designer 中使用

1. 打开 Altium Designer，新建一个 PCB 工程（File -> New -> Project -> PCB Project）
2. 将 `GenerateStickInsertSchematic.pas` 复制到工程目录
3. 菜单 DXP -> Run Script -> 选择该 .pas 文件 -> 执行 `GenerateStickInsertSchematic`
4. 脚本自动生成 `StickInsert_Control.SchDoc` 原理图
5. 检查元件库引用（Miscellaneous Devices.IntLib / Miscellaneous Connectors.IntLib 为AD自带库）
6. 编译工程（Project -> Compile PCB Project），检查无错误后可继续绘制PCB

### 三、电路模块说明

| 模块 | 元件 | 功能 |
|------|------|------|
| 电源 | P1 DC24V | 系统供电，PLC与电磁阀共用24V直流 |
| PLC主控 | U1 CPU 1214C | 西门子S7-1200（或兼容三菱FX），执行差异化延时同步控制算法 |
| 电磁阀1 | YV1 | 短行程气缸（30mm棒签），PLC输出Q0.0，延时250ms启动 |
| 电磁阀2 | YV2 | 中行程气缸（45mm棒签），PLC输出Q0.1，延时125ms启动 |
| 电磁阀3 | YV3 | 长行程气缸（60mm棒签），PLC输出Q0.2，立即启动（基准） |
| 到位传感器 | SQ1~SQ3 | 气缸到位反馈，PLC输入I0.0~I0.2，用于同步性判定 |
| 急停 | SB1 | 常闭急停按钮，PLC输入I0.3，触发后切断所有输出 |
| 过载保护 | FR1 | 过载继电器，PLC输入I0.4，负载超阈值停机告警 |
| 端子排 | XT1 | 8P端子排，连接外部气缸、传感器、电源 |

### 四、PLC I/O 分配表

| 地址 | 类型 | 功能 |
|------|------|------|
| Q0.0 | DO | 电磁阀1（短缸）输出 |
| Q0.1 | DO | 电磁阀2（中缸）输出 |
| Q0.2 | DO | 电磁阀3（长缸）输出 |
| I0.0 | DI | 气缸1到位传感器 |
| I0.1 | DI | 气缸2到位传感器 |
| I0.2 | DI | 气缸3到位传感器 |
| I0.3 | DI | 急停按钮（常闭） |
| I0.4 | DI | 过载保护继电器 |

### 五、控制逻辑

1. **差异化延时补偿**：长缸（60mm）立即启动，中缸（45mm）延时125ms，短缸（30mm）延时250ms，使三缸同时到达插入位
2. **同步收尾控制**：到位传感器反馈后，PLC判定三缸到位时间差，偏差>1.5mm触发闭环补偿
3. **过载保护**：负载电流超阈值（85%）立即切断对应气缸输出并告警
4. **急停**：SB1常闭断开 -> 所有电磁阀输出切断
5. **控制周期**：10ms（对应PLC扫描周期）

### 六、与上位机（Qt界面）的关系

- Qt界面通过串口/Modbus与PLC通信，实时显示三缸位置曲线
- 可在Qt界面调整延时补偿参数并下发到PLC
- 运行日志、同步性判定结果在Qt界面可视化展示
