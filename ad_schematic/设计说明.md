## 一、设计概述

本图是"三棒签同步插签设备"的电控板原理图：**AT89C52（8051）主控 + 三路电磁阀低边驱动 + 三路到位检测 + 急停 + USB 串口 + 24V/5V 电源**。

与 v1.0 的本质区别：主控从 PLC 改为单片机，所有 I/O 由固件直接控制（`keil_firmware\`），与 Proteus 仿真、Qt 上位机使用同一套 UART 协议（`doc\UART_PROTOCOL_v1.md`）。

## 三、电路模块

| 模块 | 器件 | 网络 | 说明 |
|---|---|---|---|
| 主控 | U1 AT89C52（DIP-40） | `+5V`/`GND`/`XTAL1/2`/`RESET` | 11.0592MHz，EA(31) 接高用片内 ROM |
| 时钟 | X1 + C1/C2 30pF | `XTAL1`/`XTAL2` | 9600bps 零误差（TH1=0xFD） |
| 复位 | C3 10µF + R1 10k（+S2 可选） | `RESET` | **高电平复位**：上电 RST=5V→0V |
| 阀驱动 | U3 ULN2003A | `DRV_YV1/2/3` → `YV1/2/3` | IN1/2/3 → **OUT1(16)/OUT2(15)/OUT3(14)**；COM(9)=+24V 供内部续流 |
| 阀接口 | J1/J2/J3 XH2.54-2P | `YV1/2/3` + `+24V` | 短 30 / 中 45 / 长 60 mm |
| 到位检测 | J4 + R2/R3/R4 10k | `SQ1/2/3` | 干簧管/接近开关对 GND 闭合，高=到位 |
| 急停 | S1（常闭）+ R5 10k | `SB1` | 正常=0，按下=1；固件取反判急停 |
| 指示 | D1/D2 + R6/R7 470Ω | `LED_RUN`/`LED_ALM` | 低有效，绿=运行、红=报警 |
| 串口 | U4 CH340C（SOP-16）+ C8 | `MCU_RXD/TXD`、`USB_DP/DM` | V3(4) 外接 100nF；USB-B 座 J6 |
| USB 供电 | D4 1N5819 | `VBUS_USB` → `+5V` | 单向：USB 可给板供电，板不反灌 PC |
| 温度预留 | J5 + R8 4.7k | `DQ_TEMP` | DS18B20 单总线 |
| 气压预留 | J7 + R9/R10 4.7k | `I2C_SDA/SCL` | BMP280 |
| 电源 | J8 → F1 2A → D3 1N5819 → U2 7805 | `+24V`/`+5V`/`GND` | C6 470µF + C5/C7/C4 100nF |
| P0 上拉 | RP1 10k×8 | `P0_0~P0_7` | P0 未使用，可 DNP |

## 四、与固件 / 上位机的对应

| 固件符号 | 引脚 | 外设 | 协议字段 |
|---|---|---|---|
| `YV1/YV2/YV3` | P1.0/1.1/1.2 | 三路阀 | 命令帧的阀位图 |
| `SQ1/SQ2/SQ3` | P2.0/2.1/2.2 | 到位 | 状态帧的到位位图 |
| `SB1` | P2.3 | 急停 | 状态帧的急停位（1=急停） |
| `LED_RUN/ALM` | P3.2/3.3 | 指示灯 | 低有效 |
| `UART` | P3.0/P3.1 | CH340C | 9600-8N1，见 `UART_PROTOCOL_v1.md` |

固件侧引脚定义与上表**必须逐条一致**；任何改动要同时改 `keil_firmware`、`Proteus`、`Qt` 三处，否则协议对不上。

## 五、v16 的已知缺陷（v17 修正项）

| 编号 | 等级 | 问题 | 后果 |
|---|---|---|---|
| F1 | 🔴 阻断 | C3/R1 接反，RST 被永久拉高 | 上电即处于复位态，程序不跑 |
| F2 | 🔴 阻断 | 阀接在 OUT7/6/5，而 IN7/6/5 悬空 | 三路阀全部不动作 |
| F3 | 🔴 阻断 | 没有 24V 进线端子/保险 | 实物无处接 24V |
| F4 | 🟠 高 | 缺去耦电容 | 阀动作瞬间易复位/跑飞 |
| F5 | 🟠 高 | CH340C 只有 6 脚符号 | 与 SOP-16 封装对不上，串口必不通 |
| F6/F7 | 🟠/🟡 | DS18B20、I2C 无上拉 | 预留功能不可用 |
| F8 | 🟠 高 | USB VBUS 直连 +5V | 两路 5V 硬并联，可能反灌 PC |
| F9~F11 | 🟡 建议 | 驱动上拉、7805 虚构脚、单脚假网络 | 影响可靠性与网表可读性 |

逐条修正与执行步骤见 `doc\目标网表_v17.md` §1 与 `给千问办公_AD_v17修正工单.md`。

## 六、验收

1. **连通性**：AD `DM_Compile`，`Error=0`、`Floating=0`、无单脚网络。
2. **网表一致**：与 `目标网表_v17.csv` 逐网比对，差异 0。
3. **记录数护栏**：元件/位号数 = 目标位号数，其余记录只增不减。
4. **电气点测**：上电 RST 由 5V 降到 0V；阀吸合时 YV 端子对地 <1V；P1.x 高电平 ≥2.4V。
