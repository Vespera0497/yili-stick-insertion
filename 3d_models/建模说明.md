# 设备3D建模说明

## 项目：伊利雪糕三棒签同步插签设备

### 一、建模软件

| 软件 | 用途 |
|------|------|
| SolidWorks / Fusion 360 | 机械结构设计（首选） |
| FreeCAD | 开源CAD建模 |
| Rhino 8 | 曲面造型，工业设计 |
| Blender | 渲染、动画、效果图 |

### 二、设备结构组成

```
┌─────────────────────────────────┐
│         机架（铝型材框架）       │
├─────────┬─────────┬─────────┤
│  气缸1   │  气缸2   │  气缸3   │
│  (短缸)  │  (中缸)  │  (长缸)  │
│  30mm   │  45mm   │  60mm   │
├─────────┴─────────┴─────────┤
│       雪糕模具定位工装          │
├───────────────────────────────┤
│       传送带（流水线）         │
└───────────────────────────────┘
```

### 三、建模步骤

1. **机架建模**：用4040铝型材搭建设备框架
2. **气缸安装板**：设计三块气缸安装板，分别对应三个不同行程的气缸
3. **气缸模型**：选择标准SC系列气缸模型（SC32x30、SC32x45、SC32x60）
4. **电磁阀安装**：在机架侧面安装电磁阀组
5. **传感器安装**：在气缸两端安装磁性开关
6. **雪糕模具定位**：设计雪糕模具定位工装，保证位置精度
7. **渲染出图**：用Blender或Keyshot渲染效果图

### 四、演示用3D模型内容

- 设备整体外观图
- 三气缸位置布置图
- 电磁阀和传感器安装位置
- 工作流程动画（三个气缸同步插签过程）

### 五、与项目其他部分的配合

| 模块 | 对应3D模型部分 |
|------|---------------|
| 控制算法 | 气缸运动轨迹、同步插签过程 |
| 上位机 | 界面展示数据与3D模型联动 |
| AD原理图 | 电气元件在设备上的安装位置 |
| Proteus仿真 | 硬件电路与3D模型对应 |
