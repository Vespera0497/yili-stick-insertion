## 三、口径提醒（照实写，不美化）

1. **AD 原生 DRC 报告、设计规则、PcbDoc 全部保持原样**：`Violations Detected: 42 / Waived 0`，MD5 仍为 `4d38dedc…`。本轮未 Waive、未放宽规则、未改板、未重跑 DRC。图页与处置单**不写「DRC 全绿 / 0 违规」**。
2. 板厂参数是**公开一般能力**，不是本板厂对本板的书面承诺；正式投板须由板厂在确认单上确认。
3. 装配图元件轮廓取自 GTO 丝印 Gerber，不含焊盘、过孔、铜箔与网表；这些以 GTL / GBL / GTS / GBS / Excellon 为准。
4. 板级 3D 专业图是离线按标称封装外形生成的几何模型（附 STEP / STL），**不是 AD 原生 PCB 3D 视图**。
5. 爆炸图为独立出图装配，无配合约束，仅表达零件层次与相对位置，不代表拆装工艺顺序。
6. 主要零件材料按工程用途指定；SOLIDWORKS 材质库赋值接口在本机返回 False，零件当前为外观着色。质量属性 12.3048 kg 是含简化上料段的**当量质量**，不作整机重量。
7. 2 条投板前处理项是设计上客观存在的 DFM 偏差，方案与坐标已给出并列进板厂确认单；不是通过改规则「消项」得到的 0 违规。
